Team 5 · three pitch concepts

Same seven beats and the same sourced facts, three different heroes. Each is 7 screens with a 3-minute script. Keys: → ← move · S script · T restart the timer · add ?present to hide the script. Live numbers come from race-data.js: refresh it with python3 judges/pitch/a5/race_data.py.

A · The Race

The hero is the score line. One chart of all 18 teams stays on screen; each beat zooms into a jump or a drop and names its cause.

light · editorial · real leaderboard data

B · Lab notebook

The hero is the method. Each spread is an experiment: prediction, measurement, stamp. Wrong findings stay on the page, crossed out.

paper · typewriter + red pen

C · Control room

The hero is the multi-agent system. The agent graph stays on screen; each beat replays a real incident and lights the agents involved. Mistakes add nodes.

dark · console · incident replays
